# val exception handler

**Author:** lil-skies
**Source:** mcp-gamehacking/skills/ags-val-exception-handler

## Description

This project is a proof of concept demonstrating exploitation of Valorant/Vanguard's exception handling mechanism. It analyzes how Vanguard processes hardware exceptions and vectored exception handlers, documenting potential weaknesses in the anti-cheat's exception dispatch flow that could be leveraged for code execution or detection evasion. It is aimed at anti-cheat researchers studying Vanguard's kernel-level protection and exception handling architecture.
