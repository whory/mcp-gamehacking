# HIGU ntcall

**Author:** jnastarot
**Source:** mcp-gamehacking/skills/ags-higu-ntcall

## Description

This project focuses on direct System Calls.
Functions with ENUM are also supported, but most of them crash the process at the stage of calling the parameter conversion.
It is mainly useful for low-level Windows, Linux, and mobile researchers working in the some tricks / windows ring3 area.
