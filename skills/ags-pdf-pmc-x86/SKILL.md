# PDF PMC X86

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-pdf-pmc-x86

## Description

This project hosts a PDF study on Performance Monitoring Counters (PMC / PMI) on the x86 architecture.
The archive is documentation-focused and is useful as background for hardware-performance-counter based monitoring, telemetry, and related Windows research.
It is mainly useful for low-level systems and game security researchers studying CPU performance counters and detection telemetry.
