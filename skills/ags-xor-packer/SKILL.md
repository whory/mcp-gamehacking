# xorPacker

**Author:** nqntmqmqmb

## Description

This project is a simple packer working with all PE files which cipher your exe with a XOR implementation.
It is primarily written in C# and centers on debugging.
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / binary packer area.
