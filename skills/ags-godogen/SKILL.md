# godogen

**Author:** htdt
**Source:** mcp-gamehacking/skills/ags-godogen

## Description

This project provides autonomous game development for Godot, Bevy, and Babylon.js with Claude Code and Codex.
It plans features, generates assets, and uses screenshot-guided self-repair loops organized along the engine axis.
It is mainly useful for game developers, reverse engineers, and tooling builders working in the game develop / ai agents area.
