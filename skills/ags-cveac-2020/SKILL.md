# CVEAC 2020

**Author:** thesecretclub
**Source:** mcp-gamehacking/skills/ags-cveac-2020

## Description

This project is a proof-of-concept Windows kernel driver exploiting a vulnerability in EasyAntiCheat's kernel module. The C++ WDK driver includes EAC-specific analysis code, kernel module enumeration, PE parsing, hook installation, and NMD assembly integration for runtime code manipulation. It is mainly useful for anti-cheat security researchers studying EasyAntiCheat kernel driver vulnerabilities and anti-cheat bypass techniques.
