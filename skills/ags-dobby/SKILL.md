# Dobby

**Author:** jmpews
**Source:** mcp-gamehacking/skills/ags-dobby

## Description

This project is a lightweight, multi-platform, multi-architecture hook framework.
It is primarily written in C/C++ and C++ and centers on kernel-level work, networking, and plugin development.
It is mainly useful for graphics programmers and Windows game tooling developers working in the directx / hook area.
