**Author:** wbenny

## Description

This project is a simple project with one goal - make Detours dependent only on NTDLL.DLL without any modifications of the original code.
You can look at my project [injdrv][injdrv] to get an idea about how is this done.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / hook area.
