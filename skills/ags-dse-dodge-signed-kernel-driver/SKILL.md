# DSEDodge Signed Kernel Driver

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-dse-dodge-signed-kernel-driver

## Description

A signed kernel driver project designed to bypass Windows Driver Signature Enforcement (DSE).
Leverages a legitimately signed driver certificate to load kernel code without triggering DSE validation failures.
