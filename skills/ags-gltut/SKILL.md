# gltut

**Author:** paroj
**Source:** mcp-gamehacking/skills/ags-gltut

## Description

This project is a comprehensive OpenGL tutorial with progressive C++ examples and detailed XML-based documentation covering core graphics concepts. It includes tutorial chapters on vector math, coordinate systems, lighting, texture mapping, and advanced rendering techniques, built with CMake and Lua-based asset generation scripts. It is mainly useful for graphics programmers and game developers learning modern OpenGL rendering fundamentals and 3D graphics theory.
