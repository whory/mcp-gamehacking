# android kernel xiaomi sweet

**Author:** fiqri19102002
**Source:** mcp-gamehacking/skills/ags-android-kernel-xiaomi-sweet

## Description

This project is the Android kernel source for Xiaomi Sweet (Redmi Note 10 Pro) with KernelSU integration patches. It includes the full Qualcomm kernel tree with Android build system integration, KernelSU hook patches, and device-specific configurations. It is mainly useful for Android kernel developers and mobile security researchers working with KernelSU-enabled custom kernels on Qualcomm-based Xiaomi devices.
