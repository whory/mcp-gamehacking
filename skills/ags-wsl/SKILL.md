## Description

Open-source components of Windows Subsystem for Linux, including the wsl.exe/wslconfig.exe front-end, Lxss Manager service, Plan 9 filesystem (DrvFS) integration, GNS networking stack, init/systemd orchestration, and the lightweight VM infrastructure for running unmodified Linux ELF binaries on Windows.
