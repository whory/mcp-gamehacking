# MOABile

**Author:** jafarm189
**Source:** mcp-gamehacking/skills/ags-moa-bile

## Description

MOABile is an all-in-one mobile security toolkit that unifies professional testing utilities into a single text-based interface for assessing Android and iOS application security from a desktop computer. Written in Python, it supports simultaneous multi-device management, dual-pane file transfer between host and mobile devices, live screen mirroring via scrcpy, and automated setup of Frida and Objection for runtime app inspection and exploration. The toolkit integrates ADB for Android along with iproxy and ioscpy for iOS connectivity, and exposes these capabilities through an arrow-key navigable terminal UI with real-time status updates. It is aimed at penetration testers, mobile security researchers, and developers who need an accessible way to perform local security assessments on devices they own.
