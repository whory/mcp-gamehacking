# dxgkrnl hook

**Author:** vmcall
**Source:** mcp-gamehacking/skills/ags-dxgkrnl-hook

## Description

This project focuses on this hooks the graphics kernel subsystem to allow manipulation of the screen buffer, for more info see the write-up.
The player boxes in this video is drawn by using that hook.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / render/draw area.
