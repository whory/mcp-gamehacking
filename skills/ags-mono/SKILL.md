# mono

**Author:** mono
**Source:** mcp-gamehacking/skills/ags-mono

## Description

Open-source implementation of the .NET Framework runtime (CLR) including a JIT/AOT compiler, garbage collector (SGen), class libraries, and an embeddable C API. Widely used as the scripting backend in Unity game engine, providing IL execution, P/Invoke interop, and managed-to-native bridging that is a primary target for game modding and security research.
