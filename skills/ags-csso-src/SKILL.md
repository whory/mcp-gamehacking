**Author:** gmh5225

## Description

This project is source code or reverse-engineered materials from Counter-Strike: Source Offensive (CSSO) or a similar Source engine title. It contains client/server game logic, weapon mechanics, player movement, and engine interface code from the Source engine. The C++ codebase provides reference material for Source engine game internals. It is aimed at Source engine researchers and game security analysts studying engine architecture.
