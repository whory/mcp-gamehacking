# KvcForensic

**Author:** wesmar
**Source:** mcp-gamehacking/skills/ags-kvc-forensic

## Description

A cross-platform LSASS credential forensics tool that extracts Windows authentication secrets (WDigest, Kerberos, DPAPI keys) from live memory or process dumps using signature scanning and crypto decryption, supporting both Windows and Linux.
