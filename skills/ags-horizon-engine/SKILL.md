# HorizonEngine

**Author:** harukumo
**Source:** mcp-gamehacking/skills/ags-horizon-engine

## Description

This project focuses on 3D rendering engine.
Horizon Engine is currently only supported on Windows and only target modern graphics APIs (Direct3D 12, Vulkan, Metal).
It is mainly useful for game developers, engine programmers, and graphics researchers working in the game engine / source area.
