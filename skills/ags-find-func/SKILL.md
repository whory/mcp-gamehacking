# FindFunc

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-find-func

## Description

An IDA Pro plugin that searches for functions matching specific byte pattern criteria or characteristics.
Allows filtering functions by instruction sequences, operand types, cross-references, and other properties to quickly locate target functions during reverse engineering.
