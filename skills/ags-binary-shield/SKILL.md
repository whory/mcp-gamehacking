# BinaryShield

**Author:** connorjaydunn
**Source:** mcp-gamehacking/skills/ags-binary-shield

## Description

This project is an open-source, bin-to-bin x86-64 code virtualizer designed to offer strong protection against reverse engineering efforts.
It translates commonly used x86-64 instructions into a custom bytecode, which is executed by a secure, purpose-built virtual machine.
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / obfuscation engine area.
