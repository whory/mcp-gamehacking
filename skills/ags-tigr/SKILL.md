# tigr

**Author:** erkkah
**Source:** mcp-gamehacking/skills/ags-tigr

## Description

This project is a tiny cross-platform graphics library, providing a unified API for Windows, macOS, Linux, iOS and Android.
TIGR's core is a simple framebuffer library.
It is mainly useful for engine and tooling developers working on asset pipelines working in the image codec area.
