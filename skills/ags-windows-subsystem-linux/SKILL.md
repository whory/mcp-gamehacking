# windows subsystem linux

**Author:** sxlmnwb
**Source:** mcp-gamehacking/skills/ags-windows-subsystem-linux

## Description

This project is a Linux kernel source tree associated with Windows Subsystem for Linux (WSL) research and builds.
The archive contains the full kernel layout (arch, drivers, fs, and related subsystems) rather than a small WSL userspace wrapper.
It is mainly useful for Windows subsystem and kernel researchers studying WSL's Linux kernel side.
