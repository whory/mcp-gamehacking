# Genshin GenshinData

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-genshin-genshin-data

## Description

This project is a Genshin Impact live-game data dump (GenshinData) collecting extracted configuration and content data from the client.
It is intended as a research/data mirror for character, weapon, and related game tables rather than a full game client.
It is mainly useful for private-server and game-data researchers studying Genshin Impact datasets.
