**Author:** not-matthias

## Description

This project focuses on dumping processes using the power of kernel space.
Some of these programs are available for free, but of course they won't be as good as the paid ones.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / windows kernel explorer area.
