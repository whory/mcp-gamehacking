**Author:** urho3d

## Description

This project is the founder of Urho3D (Lasse Öörni) is currently working on Turso3D.
Urho3D is a free lightweight, cross-platform 2D and 3D game engine.
It is mainly useful for game developers, engine programmers, and graphics researchers working in the game engine / source area.
