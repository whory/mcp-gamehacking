# thats no pipe

**Author:** synacktiv

## Description

A Frida-based Windows named pipe I/O interception toolkit that hooks NtReadFile, NtWriteFile, NtWaitForSingleObject, and IoQueue operations to monitor, record, and manipulate pipe communications for protocol analysis and fuzzing.
