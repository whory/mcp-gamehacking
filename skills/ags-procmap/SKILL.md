# procmap

**Author:** joaomlneto
**Source:** mcp-gamehacking/skills/ags-procmap

## Description

C++14 library for parsing Linux /proc/pid/maps into structured MemorySegment objects exposing address ranges, permission flags, file offsets, and backing file paths, providing a programmatic interface for memory layout analysis of running processes useful in memory forensics and game security tooling.
