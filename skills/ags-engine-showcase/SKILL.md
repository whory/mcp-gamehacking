**Author:** nitaigao

## Description

This project is an older custom C++ game-engine showcase with docs, Lua/UI layouts, level assets, networking notes, and related runtime configuration.
The archive includes engine-adjacent third-party pieces plus game content under etc/ and documentation under doc/.
It is mainly useful for game developers and engine programmers studying legacy engine layouts and tooling.
