# WickedEngine

**Author:** turanszkij
**Source:** mcp-gamehacking/skills/ags-wicked-engine

## Description

This project focuses on c++ 3D.
If you want to develop a C++ application that uses Wicked Engine, you can build the WickedEngine_Windows static library project and link against it.
It is mainly useful for game developers, engine programmers, and graphics researchers working in the game engine / source area.
