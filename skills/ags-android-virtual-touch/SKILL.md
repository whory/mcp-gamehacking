# android virtualTouch

**Author:** muchenspace
**Source:** mcp-gamehacking/skills/ags-android-virtual-touch

## Description

Android native binary (ARM64) that injects virtual touch events into the Linux input subsystem by writing to /dev/input/event* device nodes using the uinput framework. Built with the Android NDK, it simulates tap, swipe, and multi-touch gestures programmatically for game automation and input testing on rooted devices.
