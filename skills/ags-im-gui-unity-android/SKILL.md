# ImGui Unity Android

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-im-gui-unity-android

## Description

An ImGui integration for Unity games on Android providing in-game overlay menus.
Renders Dear ImGui interfaces through OpenGL ES within Unity's rendering pipeline for building mod menus and debug interfaces on Android.
