# maplestory artale explab

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-maplestory-artale-explab

## Description

This project is an experience calculator and leveling guide tool for MapleStory Artale, a specific MapleStory server or version. It calculates optimal training spots, experience rates, and leveling paths based on character class, level, and available content. It is aimed at MapleStory Artale players optimizing their leveling progression.
