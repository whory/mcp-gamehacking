# AvastHV

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-avast-hv

## Description

This project documents or exploits Avast antivirus's hypervisor component for kernel-level operations. It demonstrates using Avast's signed hypervisor driver to gain elevated privileges or execute arbitrary code in hypervisor context, leveraging Avast's trusted driver status to bypass DSE and anti-cheat protections. It is aimed at kernel security researchers studying BYOVD opportunities in antivirus hypervisor components.
