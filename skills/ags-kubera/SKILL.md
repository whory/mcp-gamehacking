# KUBERA

**Author:** binsnake
**Source:** mcp-gamehacking/skills/ags-kubera

## Description

This project is a x86 environment emulator for Windows user and kernel binaries.
It is aiming to be platform-independent and designed for research.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / dynamic binary instrumentation area.
