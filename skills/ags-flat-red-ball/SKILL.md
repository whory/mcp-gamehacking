# FlatRedBall

**Author:** vchelaru
**Source:** mcp-gamehacking/skills/ags-flat-red-ball

## Description

This project is FlatRedBall, a mature C# / .NET 2D game engine with an editor, runtime libraries, and add-ons for content loading, scripting, and debugging.
It targets productive 2D game development on modern .NET with frequent maintenance and a full editor-driven workflow.
It is mainly useful for game developers building 2D titles and for researchers inspecting a complete managed game-engine codebase.
