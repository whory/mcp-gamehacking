# GameEngine CX3D

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-game-engine-cx3d

## Description

This project is an easy to use C++ 3D Game Framework.
The CX3D Framework is an easy to use Game Framework for the development of 3D Games in C++.
It is mainly useful for game developers, engine programmers, and graphics researchers working in the game engine / source area.
