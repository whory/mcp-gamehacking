# LeagueSkinChanger

**Author:** gmh5225

## Description

An internal skin changer for League of Legends with automatic skin database updates.
Modifies champion, minion, and jungle mob skins at runtime through DirectX 9/11 hooks with an ImGui configuration menu supporting unlimited skin swaps per game.
