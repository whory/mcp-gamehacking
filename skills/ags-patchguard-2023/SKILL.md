# Patchguard 2023

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-patchguard-2023

## Description

This project is research on Windows PatchGuard (Kernel Patch Protection) as of 2023, documenting its internal workings, trigger mechanisms, and potential bypass techniques. It analyzes PatchGuard's timer-based verification, context encryption, protected structure list, and recovery routines. It is aimed at Windows kernel researchers studying PatchGuard's evolving protection mechanisms and bypass methods.
