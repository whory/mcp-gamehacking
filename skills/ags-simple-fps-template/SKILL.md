**Author:** tomlooman

## Description

This project focuses on uE4 FPS Demo.
This code "bloats" the template to look a lot more complex than neccessary if you are simply looking to start with C++ in Unreal Engine.
It is mainly useful for game developers, reverse engineers, and tooling builders working in the game develop / source area.
