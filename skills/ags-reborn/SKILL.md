# Reborn

**Author:** realTristan
**Source:** mcp-gamehacking/skills/ags-reborn

## Description

This project is a Rust-based Fortnite cheat framework with a web server backend, SQLite database, and a Discord bot interface. It provides a modular architecture with separate crates for the cheat server, bot commands, and client communication. It is mainly useful for game security researchers studying Rust-based cheat frameworks and web-controlled game modification architectures.
