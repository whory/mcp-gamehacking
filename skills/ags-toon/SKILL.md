# Toon

**Author:** benjinx
**Source:** mcp-gamehacking/skills/ags-toon

## Description

This project is a modular C++ Game Engine, designed to easily create Graphics demos.
It is primarily written in C++ and C/C++ and centers on driver development, OpenGL, and Vulkan.
It is mainly useful for game developers, engine programmers, and graphics researchers working in the game engine / source area.
