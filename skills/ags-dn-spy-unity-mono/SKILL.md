# dnSpy Unity mono

**Author:** dnSpy
**Source:** mcp-gamehacking/skills/ags-dn-spy-unity-mono

## Description

This project provides patched Unity Mono sources and build tooling used by dnSpy to produce mono.dll / mono-2.0-bdwgc.dll builds with soft-debugger support enabled.
It includes an umpatcher helper and guidance for bringing up debugging-enabled Mono runtimes across Unity versions.
It is mainly useful for reverse engineers and cheat researchers debugging managed Unity games with dnSpy.
