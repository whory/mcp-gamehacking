# GDB Windows Binaries

**Author:** noword
**Source:** mcp-gamehacking/skills/ags-gdb-windows-binaries

## Description

This project focuses on gDB.
Compiled with mingw-w64 v12.2.0, includes all architectures, TUI supported, python supported, without any other dll dependencies except Windows own.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / debugging area.
