# ethersplay

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-ethersplay

## Description

This project is Ethersplay, a Binary Ninja plugin for disassembling Ethereum Virtual Machine (EVM) bytecode. It adds EVM instruction decoding, control flow graph generation, and cross-reference analysis for smart contract binaries within Binary Ninja. The plugin helps analyze compiled Solidity smart contracts. It is aimed at blockchain security auditors analyzing Ethereum smart contract bytecode.
