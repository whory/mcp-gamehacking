# UnrealImGuiTools

**Author:** nakdeyes
**Source:** mcp-gamehacking/skills/ags-unreal-im-gui-tools

## Description

This project is a set of tools and utilities for use with Unreal Engine projects using ImGui.
It also provides a small framework to make writing your own game specific tool windows a bit more quickly and easily.
It is mainly useful for game developers, engine programmers, and graphics researchers working in the game engine / game engine plugins:unreal area.
