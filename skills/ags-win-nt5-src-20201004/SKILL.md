# WinNT5 src 20201004

**Author:** jiubanlo
**Source:** mcp-gamehacking/skills/ags-win-nt5-src-20201004

## Description

This project hosts extracted Windows NT 5.x (Windows 2000 / XP / Server 2003 era) source material organized under an NT/ tree covering base, drivers, windows, net, shell, and related components.
It is a large historical Windows source corpus useful for studying kernel, Win32, and subsystem implementation details from that generation.
It is mainly useful for Windows kernel and platform security researchers analyzing NT5-era internals.
