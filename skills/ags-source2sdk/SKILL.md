**Author:** neverlosecc

## Description

This project focuses on this repository contains the generated Source 2 SDKs for various games.
It is primarily written in C++ and centers on driver development, shader work, and rendering.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / game engine explorer:source area.
