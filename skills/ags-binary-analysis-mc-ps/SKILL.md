# BinaryAnalysisMCPs

**Author:** cycraft-corp
**Source:** mcp-gamehacking/skills/ags-binary-analysis-mc-ps

## Description

This project provides MCP (Model Context Protocol) servers for integrating AI models with binary analysis tools, starting with IDA Pro. The Python-based IDA MCP server exposes function analysis, cross-references, variable inspection, and utility tools through a structured API that enables LLM-driven reverse engineering workflows. It is mainly useful for reverse engineers seeking AI-augmented binary analysis through MCP-compatible language models.
