# UE4 Apk Dumper

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-ue4-apk-dumper

## Description

This project is a tool for dumping Unreal Engine 4 SDK data from Android APK games. It extracts UObject class hierarchies, property offsets, and function pointers from UE4 mobile game processes on Android for use in mobile game cheat development. It is aimed at mobile game reverse engineers generating UE4 SDKs from Android game packages.
