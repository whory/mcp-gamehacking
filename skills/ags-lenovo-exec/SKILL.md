# lenovo exec

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-lenovo-exec

## Description

This project exploits a Lenovo kernel driver vulnerability for arbitrary kernel code execution. It abuses the Lenovo driver's insecure IOCTL interface to execute custom code in kernel mode, demonstrating a BYOVD exploitation chain from user-mode to kernel code execution. It is aimed at BYOVD researchers studying Lenovo driver vulnerabilities.
