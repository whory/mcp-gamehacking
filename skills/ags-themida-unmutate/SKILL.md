# themida unmutate

**Author:** ergrelet
**Source:** mcp-gamehacking/skills/ags-themida-unmutate

## Description

This project is a Python 3 tool to statically deobfuscate functions protected by Themida, WinLicense and Code Virtualizer 3.x's mutation-based obfuscation.
The tool has been tested on Themida up to version 3.1.9 .
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / fix themida area.
