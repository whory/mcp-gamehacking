# genmc

**Author:** patois
**Source:** mcp-gamehacking/skills/ags-genmc

## Description

This project is an IDAPython script and plugin that displays Hex-Rays decompiler microcode intermediate representation. It provides visual inspection of the microcode generated during decompilation, helping developers understand and debug Hex-Rays microcode plugin development. It is mainly useful for IDA Pro plugin developers and reverse engineers working with Hex-Rays microcode APIs for custom decompiler extensions.
