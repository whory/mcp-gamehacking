# Uncloaking RAID0 HWID Serials

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-uncloaking-raid0-hwid-serials

## Description

This project demonstrates techniques for uncloaking or reading RAID0 disk serial numbers and hardware IDs that HWID spoofers attempt to hide. It shows how anti-cheat systems can retrieve true hardware identifiers from RAID configurations even when spoofing tools attempt to modify them. It is aimed at anti-cheat developers building HWID detection systems and researchers studying HWID spoofing limitations.
