# mir2

**Author:** Suprcode
**Source:** mcp-gamehacking/skills/ags-mir2

## Description

This project is a full open-source client and server implementation for The Legend of Mir 2. It is built mainly in C# and includes the game client, server, launcher, administrative tools, and supporting data utilities in one codebase. The repository emphasizes a modular managed architecture, performance improvements, and compatibility with custom content and community extensions. It is mainly used by private server developers and preservation-focused communities maintaining and extending classic MMORPG infrastructure.
