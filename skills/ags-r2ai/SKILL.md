# r2ai

**Author:** radareorg
**Source:** mcp-gamehacking/skills/ags-r2ai

## Description

This project is r2ai, an LLM-based reversing assistant integrated with radare2 for interactive binary analysis workflows.
It connects language-model tooling to radare2 sessions to help inspect, explain, and automate reverse-engineering tasks.
It is mainly useful for reverse engineers using radare2 who want LLM-assisted analysis of game and security binaries.
