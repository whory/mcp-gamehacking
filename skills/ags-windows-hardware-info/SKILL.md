# WindowsHardwareInfo

**Author:** paradoxwastaken
**Source:** mcp-gamehacking/skills/ags-windows-hardware-info

## Description

This project focuses on windows-Hardware-Info A project written in C++ to get hardware info on a Windows PC.
Interfaces with the Windows Management Instrumentation (WMI) service to query hardware info of interest and provides a basic command line interface.
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / detection:hwid area.
