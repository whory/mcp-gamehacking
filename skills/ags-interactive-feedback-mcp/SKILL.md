# interactive feedback mcp

**Author:** noopstudios
**Source:** mcp-gamehacking/skills/ags-interactive-feedback-mcp

## Description

This project is an MCP (Model Context Protocol) server that provides interactive user feedback capabilities to AI coding assistants. It allows the AI to request user input, confirmations, and selections through structured UI prompts during automated workflows, enabling human-in-the-loop interaction within MCP-compatible tools. It is aimed at developers building interactive AI-assisted workflows that require user feedback during execution.
