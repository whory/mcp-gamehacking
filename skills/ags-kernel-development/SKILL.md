# kernel development

**Author:** gregkh
**Source:** mcp-gamehacking/skills/ags-kernel-development

## Description

This project is a documentation and tutorial resource for Linux kernel development by Greg Kroah-Hartman. It covers the kernel development process, coding style, submitting patches, device driver development, and kernel module programming. The materials provide guidance on contributing to the upstream Linux kernel. It is aimed at aspiring Linux kernel developers and systems programmers learning kernel development workflows and conventions.
