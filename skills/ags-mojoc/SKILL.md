# Mojoc

**Author:** scottcgi
**Source:** mcp-gamehacking/skills/ags-mojoc

## Description

This project is a cross-platform, open-source, pure C game engine for mobile game.
It is based on OpenGLES3 and written in C99.
It is mainly useful for game developers, reverse engineers, and tooling builders working in the game develop / source area.
