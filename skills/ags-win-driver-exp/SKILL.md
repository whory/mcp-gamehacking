# Win Driver EXP

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-win-driver-exp

## Description

This project is a collection of Windows driver exploits targeting various vulnerable signed drivers for kernel-level access. It provides exploit code for multiple vulnerable drivers, demonstrating arbitrary kernel read/write, code execution, and process manipulation through their insecure IOCTL interfaces. It is aimed at BYOVD researchers and red team operators studying the landscape of exploitable Windows kernel drivers.
