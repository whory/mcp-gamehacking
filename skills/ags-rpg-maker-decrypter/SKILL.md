## Description

This project focuses on tool for extracting RPG Maker XP, VX and VX Ace encrypted archives.
RPG Maker Decrypter is an advanced CLI application.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / re tools area.
