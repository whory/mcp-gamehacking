# VaultGuard

**Author:** wesmar
**Source:** mcp-gamehacking/skills/ags-vault-guard

## Description

A Windows process protection tool written entirely in x64 MASM assembly that uses a kernel driver to monitor and block suspicious process access, providing anti-debugging and anti-tampering capabilities with a system tray GUI.
