# Fortnite Offsets

**Author:** Android1337
**Source:** mcp-gamehacking/skills/ags-fortnite-offsets

## Description

This project collects Fortnite memory offsets used by cheat and reverse-engineering tooling.
The original GitHub repository is no longer available; the README entry documents it as an offset dump under the Fortnite game-cheat research category.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / game:fortnite area.
