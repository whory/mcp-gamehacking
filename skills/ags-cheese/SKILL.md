# cheese

**Author:** zhuowei
**Source:** mcp-gamehacking/skills/ags-cheese

## Description

Root exploit for Meta Quest 3 and Quest 3S VR headsets (firmware v79 and below) leveraging CVE-2025-21479, a Qualcomm Adreno GPU vulnerability, to achieve temporary root and install Magisk without modifying the boot partition, building on research from Project Zero's Adrenaline exploit and Freedreno GPU documentation.
