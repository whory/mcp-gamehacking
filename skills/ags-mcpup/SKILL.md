# mcpup

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-mcpup

## Description

This project is mcpup, a tool for managing and deploying MCP (Model Context Protocol) servers. It provides utilities for discovering, installing, configuring, and running MCP servers that extend AI coding assistants with additional capabilities. It is aimed at developers setting up MCP server infrastructure for AI-assisted development workflows.
