# radius2

**Author:** radareorg
**Source:** mcp-gamehacking/skills/ags-radius2

## Description

This project focuses on fast binary emulation and symbolic execution framework using radare2.
It is primarily written in Rust and C and centers on modding and memory analysis.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / radare plugins area.
