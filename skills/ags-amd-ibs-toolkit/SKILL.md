# AMD IBS Toolkit

**Author:** jlgreathouse
**Source:** mcp-gamehacking/skills/ags-amd-ibs-toolkit

## Description

This project focuses on aMD Sampling.
IBS is a hardware mechanism that samples a subset of all of the instructions going through a processor.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / windows kernel explorer area.
