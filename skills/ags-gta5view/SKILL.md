# gta5view

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-gta5view

## Description

This project is gta5view, a tool for viewing and exporting Grand Theft Auto V snapmatic photos and save game data. It parses GTA V's proprietary file formats for in-game photos, save files, and profile data, allowing users to view, export, and manage their GTA V user-generated content outside the game. It is aimed at GTA V players and modders managing game save data and snapmatic photo collections.
