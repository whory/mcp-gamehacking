# SourceEngine2007

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-source-engine2007

## Description

This project is a Source Engine 2007 (Orange Box era) source tree mirror, covering the engine, client, server, and related modules under se2007.
It includes C++ engine internals such as networking, demos, rendering hooks into the Source stack, and game-side subsystems useful for studying that engine generation.
It is mainly useful for game developers, engine programmers, and reverse engineers working with Source Engine titles and tooling.
