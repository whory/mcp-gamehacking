# IDA2Obj

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-ida2obj

## Description

A tool that converts IDA Pro database content back into linkable object files.
Reconstructs COFF/ELF object files from IDA analysis data including relocations, symbols, and section content for binary patching and recompilation workflows.
