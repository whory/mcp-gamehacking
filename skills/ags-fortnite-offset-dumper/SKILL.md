# Fortnite Offset dumper

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-fortnite-offset-dumper

## Description

A Fortnite offset dumper that extracts current memory offsets and class layouts from the running game.
Generates structured offset data with regex-cleaned class names and hierarchical offset definitions for use in external and internal cheats.
