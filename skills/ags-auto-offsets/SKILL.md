# AutoOffsets

**Author:** masterpastaa
**Source:** mcp-gamehacking/skills/ags-auto-offsets

## Description

C++ utility that fetches current Fortnite game offsets from a remote API endpoint using the WinINet HTTP stack (InternetOpenUrlA/InternetReadFile). The offsets are retrieved from an external reversal database and can also be queried programmatically via a REST API with key-based authentication.
