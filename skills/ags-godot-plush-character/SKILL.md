# Godot Plush Character

**Author:** gtibo
**Source:** mcp-gamehacking/skills/ags-godot-plush-character

## Description

This project is a Godot Engine plugin or demo implementing plush/soft body character rendering with a stylized stuffed-animal aesthetic. It demonstrates shader-based fabric texturing, soft deformation, and procedural animation techniques for creating visually appealing plush-style 3D characters in Godot. It is aimed at Godot developers and technical artists creating stylized character rendering effects.
