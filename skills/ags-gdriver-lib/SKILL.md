# gdriver lib

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-gdriver-lib

## Description

This project is a library wrapping the GIGABYTE gdrv64.sys vulnerable driver interface for convenient kernel memory access. It provides C++ functions for reading and writing physical memory, mapping physical addresses, and performing kernel operations through gdrv's vulnerable IOCTLs. It is aimed at kernel researchers using GIGABYTE driver exploitation as a kernel access primitive.
