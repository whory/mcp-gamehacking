# DbgViewEx

**Author:** emlinhax
**Source:** mcp-gamehacking/skills/ags-dbg-view-ex

## Description

This project is a tool to log ETW Events and system debug logs.
This app is being worked on from time to time and is in its very early stage.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / re tools area.
