**Author:** ryan-weil

## Description

This project focuses on ntUserSetSysColors.
Please note that the function addresses are currently hardcoded for Windows 11 kernel 10.0.22000.376.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / driver communication area.
