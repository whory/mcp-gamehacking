# Obfu DE Scate

**Author:** user1342
**Source:** mcp-gamehacking/skills/ags-obfu-de-scate

## Description

This project is a Python-based Android APK deobfuscation tool that analyzes obfuscated class and method names to generate human-readable mappings. It produces visual HTML reports with class hierarchy diagrams and method classification to help reverse engineers navigate heavily obfuscated Android applications. It is mainly useful for Android reverse engineers and malware analysts dealing with ProGuard or R8-obfuscated APKs.
