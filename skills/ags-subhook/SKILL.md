# subhook

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-subhook

## Description

This project is a super-simple hooking library for C and C++ that works on Windows, Linux and macOS.
It supports x86 only (32-bit and 64-bit).
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / hook area.
