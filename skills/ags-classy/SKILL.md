# Classy

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-classy

## Description

An IDA Pro plugin for managing C++ classes, vtables, and function signatures during reverse engineering.
Features vtable generation from selected ranges, function-to-class assignment, Itanium name mangling, IDA struct mapping, and C header generation with a PyQt5 GUI.
