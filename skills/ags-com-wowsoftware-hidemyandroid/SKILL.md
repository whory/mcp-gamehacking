# com.wowsoftware.hidemyandroid

**Author:** Xposed-Modules-Repo
**Source:** mcp-gamehacking/skills/ags-com-wowsoftware-hidemyandroid

## Description

HideMyAndroid is a privacy-focused Xposed/LSPosed module for rooted Android 9+ devices that intercepts identifier and environment queries from target apps and returns profile-based spoofed values to reduce tracking and device fingerprinting. It supports masking device identifiers such as Android ID, GAID, IMEI, and Widevine DRM ID, hiding root, LSPosed, VPN, proxy, and developer mode, spoofing SIM, Wi-Fi, Bluetooth, GPS, timezone, and browser fingerprints, and isolating per-profile accounts and proxy settings. Built on the Xposed hooking framework, it uses a profile-based configuration system with backup, restore, and device simulation capabilities. It is aimed at users studying or bypassing app-level anti-detection and fingerprinting checks, including scenarios relevant to mobile game security, anti-cheat evasion, and reverse engineering research on Android.
