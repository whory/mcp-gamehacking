# libelevate

**Author:** notscimmy
**Source:** mcp-gamehacking/skills/ags-libelevate

## Description

This project is a C++ library for elevating handles and bypassing handle access restrictions on Windows. It exploits driver or kernel-level primitives to open processes with full access rights even when protected by anti-cheat or security software. The library provides a clean API for obtaining elevated handles that can be used for memory read/write operations. It is aimed at game security researchers studying handle elevation techniques and anti-cheat handle protection mechanisms.
