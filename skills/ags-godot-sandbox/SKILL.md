# godot sandbox

**Author:** libriscv
**Source:** mcp-gamehacking/skills/ags-godot-sandbox

## Description

This project focuses on sandboxing that enables safe modding for Godot games.
All Godot platforms are supported.
It is mainly useful for game developers, engine programmers, and graphics researchers working in the game engine / game engine plugins:godot area.
