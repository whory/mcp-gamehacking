# DirtyPipeRoot

**Author:** tiann
**Source:** mcp-gamehacking/skills/ags-dirty-pipe-root

## Description

Android application that exploits the Dirty Pipe vulnerability (CVE-2022-0847) to achieve one-click temporary root on Pixel 6 devices running vulnerable kernel versions, packaging both a vulnerability checker and a native C exploit into a user-friendly app that overwrites read-only files through Linux pipe page cache corruption.
