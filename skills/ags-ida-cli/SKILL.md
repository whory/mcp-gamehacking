# ida cli

**Author:** cpkt9762
**Source:** mcp-gamehacking/skills/ags-ida-cli

## Description

This project focuses on headless IDA Pro MCP server for AI-assisted binary analysis, powered by idalib.
It is primarily written in Rust and C/C++ and centers on reverse engineering, plugin development, and modding.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / ida plugins area.
