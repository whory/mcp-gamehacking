# perses

**Author:** mike1k
**Source:** mcp-gamehacking/skills/ags-perses

## Description

This project is a X86 code obfuscation engine that works with Portable Executable files.
The obfuscation works by replacing a specific instruction with a larger more sophisticated set that is semantically compatible to the original.
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / obfuscation engine area.
