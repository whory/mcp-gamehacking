# raylib

**Author:** raysan5
**Source:** mcp-gamehacking/skills/ags-raylib

## Description

This project is a simple and easy-to-use library to enjoy videogames programming.
It is primarily written in C and C/C++ and centers on kernel-level work, OpenGL, and Vulkan.
It is mainly useful for game developers, reverse engineers, and tooling builders working in the game develop / source area.
