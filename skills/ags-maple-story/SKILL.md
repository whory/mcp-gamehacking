# MapleStory

**Author:** ellermister
**Source:** mcp-gamehacking/skills/ags-maple-story

## Description

This project is a MapleStory private server emulator implementing the game server logic for a classic version of MapleStory. It handles login, channel, and world server functionality including character management, map navigation, monster spawning, skill processing, party/guild systems, and item transactions. The codebase emulates the MapleStory network protocol and game mechanics. It is aimed at private server developers and game server researchers studying MMO server architecture.
