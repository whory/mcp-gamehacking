# gamedev libraries

**Author:** raizam
**Source:** mcp-gamehacking/skills/ags-gamedev-libraries

## Description

This project is a collection of open source c/c++ libraries for gamedev.
The library has been written with a data-oriented philosophy: POD structures are preferred over classes, flat arrays are the preferred data structure, etc.
It is mainly useful for game developers, reverse engineers, and tooling builders working in the game develop / guide area.
