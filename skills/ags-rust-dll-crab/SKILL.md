# rust dll crab

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-rust-dll-crab

## Description

This project is a Rust-based DLL injector for Windows that provides DLL injection capabilities written in Rust. It implements various injection methods and demonstrates using Rust for Windows system programming tasks typically done in C/C++. It is aimed at Rust developers and security researchers exploring Rust for game hacking tool development.
