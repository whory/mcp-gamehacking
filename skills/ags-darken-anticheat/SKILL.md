# darken anticheat

**Author:** noahware
**Source:** mcp-gamehacking/skills/ags-darken-anticheat

## Description

This project is Darken, a proof-of-concept anti-cheat system implementing common game protection techniques. It demonstrates kernel-mode driver communication, process integrity checking, module verification, memory scanning for known signatures, debugger detection, and overlay monitoring. The C/C++ codebase provides a reference implementation of anti-cheat detection mechanisms. It is aimed at game security developers studying anti-cheat architecture and building custom protection systems.
