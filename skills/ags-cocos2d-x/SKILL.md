# cocos2d x

**Author:** cocos2d
**Source:** mcp-gamehacking/skills/ags-cocos2d-x

## Description

This project provides cocos2d-x][1] is a multi-platform framework for building 2d games, interactive books, demos and other graphical applications.
It is based on cocos2d-iphone , but instead of using Objective-C, it uses C++.
It is mainly useful for game developers, engine programmers, and graphics researchers working in the game engine / source area.
