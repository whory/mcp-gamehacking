# PUBGM1.6 DeadGame

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-pubgm1-6-dead-game

## Description

This project archives a PUBG Mobile 1.6 decompiled dump focused on libtersafe.so and libUE4.so from a large APK unpack.
It preserves historical mobile anti-cheat and Unreal native symbols/functions from that dead game version for research reference.
It is mainly useful for mobile game security researchers studying PUBGM / Tencent anti-cheat native libraries.
