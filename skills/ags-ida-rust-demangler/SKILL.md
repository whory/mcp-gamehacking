# IDARustDemangler

**Author:** timetravelthree
**Source:** mcp-gamehacking/skills/ags-ida-rust-demangler

## Description

This project focuses on rust Demangler & Normalizer.
The demangling algorithm used in this script is based on rs-dml binary so make sure you have it already installed.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / ida plugins area.
