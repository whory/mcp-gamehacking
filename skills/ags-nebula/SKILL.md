# nebula

**Author:** gscept
**Source:** mcp-gamehacking/skills/ags-nebula

## Description

This project is the fastest way to setup and test nebula is to clone the Nebula-demo instead.
It contains a setup.bat which will setup dependencies and configure a solution for you to run via fips open.
It is mainly useful for game developers, engine programmers, and graphics researchers working in the game engine / source area.
