# CUTracer

**Author:** facebookresearch
**Source:** mcp-gamehacking/skills/ags-cu-tracer

## Description

This project is a dynamic binary instrumentation tool for tracing and analyzing CUDA kernel instructions.
It cleanly separates lightweight data collection (instrumentation) from host-side processing (analysis).
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / dynamic binary instrumentation area.
