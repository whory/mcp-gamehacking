# ds4 tools

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-ds4-tools

## Description

This project provides tools for interfacing with PlayStation DualShock 4 (DS4) controllers on PC. It handles DS4 controller input reading, LED color control, touchpad data, motion sensor access, and rumble motor control through HID protocol communication. It is aimed at game developers and input device researchers working with DS4 controller features on PC platforms.
