# DIE engine web

**Author:** t0asts
**Source:** mcp-gamehacking/skills/ags-die-engine-web

## Description

A WebAssembly port of Detect It Easy (DIE) that runs the PE/ELF/Mach-O binary identification engine entirely in the browser, compiled from the original Qt-based C++ codebase via Emscripten with a web frontend.
