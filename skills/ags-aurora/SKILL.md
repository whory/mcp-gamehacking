**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-aurora

## Description

This project is Aurora, a CS2 (Counter-Strike 2) cheat providing ESP, aimbot, and visual modification features. It interacts with the Source 2 engine through schema system access and entity enumeration to extract player data and render overlays. It is aimed at game security researchers studying CS2 cheat implementations.
