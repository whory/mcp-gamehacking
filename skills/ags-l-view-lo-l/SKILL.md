# LViewLoL

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-l-view-lo-l

## Description

An external League of Legends viewing tool providing real-time game state visualization.
Reads LoL game memory externally to display minimap information, player positions, cooldown tracking, and other game data in a separate overlay.
