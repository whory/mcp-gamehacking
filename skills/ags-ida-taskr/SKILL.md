# ida taskr

**Author:** mahmoudimus
**Source:** mcp-gamehacking/skills/ags-ida-taskr

## Description

This project is a pure Python library for IDA Pro related parallel computing.
It lets you use the power of Qt (built-in to IDA!) and Python's multiprocessing to offload computationally intensive tasks to worker processes without freezing IDA Pro's UI.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / ida plugins area.
