# jumpy

**Author:** fishfolk
**Source:** mcp-gamehacking/skills/ags-jumpy

## Description

This project is a tactical 2D multiplayer shooter game built in Rust with asset-driven game design. It features cross-platform support including Cross compilation, arcade-style gameplay with effects and animations, and a modular asset system for maps, characters, and items. It is mainly useful for Rust game developers and engine researchers studying 2D multiplayer game architecture and asset pipeline design.
