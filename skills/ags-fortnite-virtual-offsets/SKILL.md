# fortnite virtual offsets

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-fortnite-virtual-offsets

## Description

This project is a small Fortnite virtual-table / view-related offset dump, listing values such as GetPlayerViewPoint, ProcessEvent, LineOfSightTo, and camera helpers.
The archive contains a single offsets text file with no additional tooling.
It is mainly useful for game security researchers studying Unreal Engine offset layouts in Fortnite-related reverse engineering.
