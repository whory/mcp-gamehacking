# cocos4

**Author:** cocos
**Source:** mcp-gamehacking/skills/ags-cocos4

## Description

This project focuses on cOCOS 4 is an open-source, high-performance, cross-platform game and interactive content development engine.
Built on a mature C++ architecture, it provides powerful rendering capabilities and flexible script bindings, supporting a "write once, run anywhere" philosophy.
It is mainly useful for game developers, engine programmers, and graphics researchers working in the game engine / source area.
