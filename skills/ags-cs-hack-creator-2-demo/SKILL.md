# CSHackCreator 2 Demo

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-cs-hack-creator-2-demo

## Description

This project is a tool which generates custom cheats based on user input, for the old Counter-Strike game without coding a single line of code.
It is primarily written in C/C++ and C++ and centers on OpenGL, Vulkan, and rendering.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / game:cs1.6 area.
