**Author:** gmh5225

## Description

This project focuses on reverse Engineered GTA III and GTA VC.
The project has also been ported to the Nintendo Switch, Playstation Vita and Nintendo Wii U.
It is mainly useful for game developers, reverse engineers, and tooling builders working in the game develop / source area.
