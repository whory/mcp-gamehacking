# Fortnite Offsets Sigs and more

**Author:** ReallReaper
**Source:** mcp-gamehacking/skills/ags-fortnite-offsets-sigs-and-more

## Description

This project is a small repository that publishes Fortnite memory offsets and related signature values.
It provides a header file with common Unreal Engine pointer chains and gameplay-relevant structure offsets used by external tools.
The content is mainly C and C++ style constants intended for quick integration into existing cheat or analysis code.
It is used as a reference dataset for game hacking updates and offset maintenance.
