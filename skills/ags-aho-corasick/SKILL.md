# aho corasick

**Author:** mischasan
**Source:** mcp-gamehacking/skills/ags-aho-corasick

## Description

High-performance Aho-Corasick multi-pattern string matching library using an Interleaved State-transition Matrix (ISM) representation that achieves both minimal memory footprint and maximum search speed. Supports memory-mapped serialization for persistent automata and provides a C API for building, querying, and dumping the compiled state machine.
