# comon

**Author:** lowleveldesign
**Source:** mcp-gamehacking/skills/ags-comon

## Description

This project focuses on trace COM.
Comon is a WinDbg extension that can help you trace COM interactions (COM class creations and interface querying).
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / windbg plugins area.
