# idasdk collection

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-idasdk-collection

## Description

This project is a collection of IDA Pro SDKs across multiple versions, archiving SDK releases for historical reference and backward-compatible plugin development. It provides headers, libraries, and examples from different IDA SDK versions. It is aimed at IDA Pro plugin developers maintaining compatibility across IDA versions.
