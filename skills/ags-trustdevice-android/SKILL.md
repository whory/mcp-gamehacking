# trustdevice android

**Author:** trustdecision
**Source:** mcp-gamehacking/skills/ags-trustdevice-android

## Description

This project is a TrustDecision device fingerprinting SDK for Android that generates unique device identifiers and risk signals for fraud detection. The Kotlin and Java-based library includes instrumented tests, privacy policy documentation, and ProGuard configuration for production deployment. It is mainly useful for anti-cheat engineers and mobile security researchers studying Android device fingerprinting and device integrity verification techniques.
