# Game Engine

Identify the exact **engine, version, build type, runtime, and artifact** before generalizing an object layout or tooling workflow. Engine internals, plugins, detectors, and SDK paths underpin modding, reverse engineering, and anti-cheat integration—especially Unreal, Unity ([[il2cpp]] / Mono), Source, Godot, and custom engines. Globals, object layouts, metadata formats, and helper APIs vary by branch, build configuration, platform, and game modifications—apply [[research-rigor]] before generalizing signatures or offsets across titles.

## Engine trust boundaries

Use [[engine-trust-boundaries]] to map which surface a claim targets before selecting tools or drawing security conclusions. Baseline the engine branch, game build/hash, platform/ABI, scripting backend (Mono vs IL2CPP vs native-only), stripping configuration, symbol availability, and plugin versions; keep reflected metadata, native/managed execution, serialized assets, in-process plugins, and client/server replication separate.

Describe attack scenarios by the boundary that must fail—untrusted content accepted by an importer, a plugin granted in-process execution, or client assertions accepted as authoritative game state—not by engine brand alone. Engine identification or object discovery alone does not establish compromise; correlate asset provenance, plugin inventory, owned-build diagnostics, serialization checks, and server-side validation. Route tick/prediction/replay ordering to game-server-security; build/update/mod distribution trust to game-supply-chain-security; transport authority and session/inventory ownership to their dedicated skills. Report the affected boundary, prerequisite, artifact, observed result, benign controls, and version-dependent limits.

| Engine | Metadata vs execution gap |
|--------|----------------------------|
| Unreal | Reflection covers annotated members; native-only fields and lifetime need separate evidence ([[unreal-object-model]]) |
| Unity IL2CPP | Stripping + AOT codegen; dump/metadata does not guarantee full type coverage ([[il2cpp]]) |
| Godot | GDExtension manifests are version/platform/build specific—verify target release |
| Source SDK | Licensed SDK game code ≠ unrestricted open source ([[source-netvars]]) |
