# pubg public

**Author:** K-cazb
**Source:** mcp-gamehacking/skills/ags-pubg-public

## Description

This project is a C++ external game assistance codebase focused on PUBG.
It includes offset-driven entity parsing, bone and camera math, ESP rendering, and aim automation logic.
The codebase also contains decryption helpers, driver-assisted memory access, and DirectX overlay components.
It is mainly used as an educational reference for game hacking methods and anti-cheat analysis.
