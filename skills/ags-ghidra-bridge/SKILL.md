# ghidra bridge

**Author:** justfoxing
**Source:** mcp-gamehacking/skills/ags-ghidra-bridge

## Description

This project focuses on python 3 bridge to Ghidra's Python scripting.
But Ghidra's Python scripting is based on Jython, which isn't in a great state these days.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / ghidra plugins area.
