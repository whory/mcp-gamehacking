# IL22CPP

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-il22cpp

## Description

A research tool for analyzing and manipulating Unity IL2CPP runtime binaries.
Provides utilities for resolving IL2CPP metadata, reconstructing managed type information, and interfacing with the IL2CPP virtual machine for game modding.
