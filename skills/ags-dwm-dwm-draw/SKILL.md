# DWM DwmDraw

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-dwm-dwm-draw

## Description

A technique for rendering overlays through the Desktop Window Manager (DWM) drawing pipeline.
Hooks into DwmDraw functions to render ESP and visual hack elements directly through the Windows compositor, making overlays invisible to screenshot-based detection.
