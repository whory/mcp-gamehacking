# cthash

**Author:** hanickadot
**Source:** mcp-gamehacking/skills/ags-cthash

## Description

This project focuses on constexpr implementation of SHA-2 and SHA-3 family of hashes.
The library also implements hash_value literals in namespace cthash::literals (suffixes in parenthesis for each hash function type).
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / compile time area.
