# execution trace viewer

**Author:** teemu-l
**Source:** mcp-gamehacking/skills/ags-execution-trace-viewer

## Description

This project is an application for viewing, editing and analyzing execution traces.
It was originally made for reverse engineering obfuscated code, but it can be used to analyze any kind of execution trace.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / debugging area.
