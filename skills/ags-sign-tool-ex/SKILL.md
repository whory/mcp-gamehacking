# SignToolEx

**Author:** hackerhouse-opensource
**Source:** mcp-gamehacking/skills/ags-sign-tool-ex

## Description

This project focuses on sign Leaked Cert.
This allows expired (leaked) certificates to be used for code-signing but does not permit spoofing Authenticode timestamps.
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / sign tools area.
