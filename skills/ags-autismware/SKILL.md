## Description

This project is a CS:GO internal cheat written in C++ providing ESP, aimbot, backtrack, skin changer, and miscellaneous gameplay modifications. It hooks into the Source engine through interface capture and VMT hooking, with an ImGui-based configuration menu. The codebase follows standard CS:GO internal cheat patterns. It is aimed at game security researchers studying Source engine cheat feature implementation.
