# DMA PCIE BOARD 75T

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-dma-pcie-board-75t

## Description

A PCIe DMA board design based on the Xilinx Artix-7 75T FPGA for hardware-level memory access.
Provides firmware and HDL sources for a custom PCIe device capable of performing DMA reads and writes to host system memory, targeting game security research and testing.
