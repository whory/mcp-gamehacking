# sigmakerex

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-sigmakerex

## Description

This project is SigMakerEx, an enhanced IDA Pro signature maker plugin with additional features beyond basic sig generation. It generates code-style, IDA-style, and x64dbg-compatible signature patterns with automatic uniqueness verification, batch generation, and clipboard integration. It is aimed at reverse engineers who frequently create and manage binary signatures in IDA Pro.
