# A146B KSU

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-a146b-ksu

## Description

This project is a custom Android kernel for the Samsung Galaxy A14 (A146B) with KernelSU support integrated. It provides a modified kernel source tree with KernelSU patches for root access management on this specific Samsung device. It is aimed at Android developers and custom ROM builders targeting Samsung A14 devices with KernelSU root.
