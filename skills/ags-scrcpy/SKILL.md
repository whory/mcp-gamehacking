# scrcpy

**Author:** Genymobile
**Source:** mcp-gamehacking/skills/ags-scrcpy

## Description

scrcpy is a cross-platform tool that mirrors and controls Android devices from a desktop over USB or TCP/IP. It is mainly implemented in C and Java and is designed for high performance, low latency, and minimal device-side footprint without root access. Key features include audio forwarding, recording, virtual display support, HID input simulation, and broad desktop platform compatibility. Its primary use case is device testing, automation, and mobile app or game debugging workflows.
