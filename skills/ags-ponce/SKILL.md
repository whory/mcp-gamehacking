# Ponce

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-ponce

## Description

This project is Ponce, an IDA Pro plugin for symbolic and taint execution. It integrates the Triton dynamic binary analysis framework into IDA, enabling symbolic execution from within the disassembler to solve path constraints, track tainted data flow, and generate inputs that reach specific code paths. It is aimed at vulnerability researchers and reverse engineers using symbolic execution for automated analysis in IDA Pro.
