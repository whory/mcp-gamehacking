# wdutf

**Author:** wpdk
**Source:** mcp-gamehacking/skills/ags-wdutf

## Description

This project is the Windows Driver Unit Test Framework (WDUTF) enables the unit testing of Windows kernel drivers using the Microsoft Unit Testing Framework for C++, which runs in user space.
Running unit tests against code written for the Windows Kernel environment is hard.
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / driver unit test framework area.
