# android emulator hypervisor driver

**Author:** google
**Source:** mcp-gamehacking/skills/ags-android-emulator-hypervisor-driver

## Description

This project is a hypervisor to accelerate [Android Emulator][android-studio].
It is made by porting KVM to Windows (Windows 8.1 or later, 64bit).
It is mainly useful for mobile platform and emulator researchers working in the android emulator area.
