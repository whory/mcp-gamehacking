# kvc

**Author:** wesmar

## Description

A Windows kernel vulnerability controller that disables Driver Signature Enforcement (DSE) by patching CI.dll options via a signed Microsoft driver, with certificate-based code signing and multiple loader strategies for unsigned driver loading.
