# LeagueSharp

**Author:** gmh5225

## Description

A League of Legends scripting and modding platform with multiple tool modules.
Includes JungleTimerHax for spectator-based jungle timers, SkinHax for in-game skin changes, and champion resize utilities using LoL's internal APIs.
