# AntiCheat

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-gmh5225-anti-cheat

## Description

This project is a reference implementation of an anti-cheat system demonstrating common game protection techniques. It includes process integrity verification, module scanning, memory pattern detection, debugger detection, overlay monitoring, and driver communication for kernel-level checks. The C/C++ codebase serves as a study reference for understanding how anti-cheat systems are structured. It is aimed at anti-cheat developers and game security researchers studying protection system architecture.
