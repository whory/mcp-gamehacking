## Description

This project is disassembler or debugger that works based on the extension plugin.
It is primarily written in C/C++ and C++ and centers on plugin development, modding, and SDK generation.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / debugging area.
