# obpo plugin

**Author:** obpo-project
**Source:** mcp-gamehacking/skills/ags-obpo-plugin

## Description

This project is the obpo core is closed source , but provided obpo-plugin is FREE & OPEN SOURCE.
This is a simple backend server written in golang, used to receive request and input to ida and uses obpo-core to deobfuscation, finally returning data to obpo-plugin client.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / fix ollvm area.
