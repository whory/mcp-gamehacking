# Software D3D9

**Author:** code-tom-code
**Source:** mcp-gamehacking/skills/ags-software-d3d9

## Description

This project focuses on dX9.
It is intended to work with real games and other programs, and eventually should support a high level of compatibility with a wide range of existing D3D9 games and programs.
It is mainly useful for graphics programmers and Windows game tooling developers working in the directx / emulation area.
