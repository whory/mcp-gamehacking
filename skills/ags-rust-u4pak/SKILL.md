# rust u4pak

**Author:** panzi
**Source:** mcp-gamehacking/skills/ags-rust-u4pak

## Description

This project provides unpack, pack, list, check and mount unreal engine 4 .pak archives.
Note that only a limited number of pak versions are supported.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / game engine explorer:unreal area.
