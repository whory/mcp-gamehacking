# headless ida mcp server

**Author:** cnitlrt
**Source:** mcp-gamehacking/skills/ags-headless-ida-mcp-server

## Description

This project focuses on mCP for IDA pro(headless.
This project uses IDA Pro's headless mode to analyze binary files and provides a suite of tools via MCP to manage and manipulate functions, variables, and more.
It is mainly useful for game developers, reverse engineers, and tooling builders working in the game develop / mcp server area.
