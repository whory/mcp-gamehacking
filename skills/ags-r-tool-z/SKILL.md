# RToolZ

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-r-tool-z

## Description

This project is RToolZ, a Windows system utility providing rootkit-like capabilities for process, module, and callback management. It can hide/unhide processes, enumerate kernel callbacks, remove notification routines, and manipulate process protection levels through a driver backend. It is aimed at kernel researchers studying system manipulation tools and rootkit techniques.
