# HelloIommuPkg

**Author:** tandasat
**Source:** mcp-gamehacking/skills/ags-hello-iommu-pkg

## Description

This project is the sample DXE runtime driver demonstrating how to program DMA remapping.
This project is meant to show a simplified yet functioning code example for learning purposes and not designed for actual use in production systems.
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / detection:dma area.
