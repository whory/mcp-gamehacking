# pandora

**Author:** pandora-analysis
**Source:** mcp-gamehacking/skills/ags-pandora

## Description

This project is an analysis framework to discover if a file is suspicious and conveniently show the results.
Note that it is strongly recommended to use Ubuntu 24.04, which comes with a more recent version of libreoffice.
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / analysis framework area.
