# AcDrv

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-ac-drv

## Description

This project is AcDrv, a Windows kernel driver for anti-cheat or security research purposes. It implements kernel-level monitoring capabilities such as process callback registration, module load tracking, memory access interception, or system call monitoring through a custom driver interface. It is aimed at kernel security researchers building or studying anti-cheat driver components.
