# IDA Pro SigMaker

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-ida-pro-sig-maker

## Description

An IDA Pro plugin for generating byte-pattern signatures from selected code regions.
Creates wildcard-masked signature patterns suitable for runtime pattern scanning in game hacking and binary analysis tools.
