# EntropyReducer

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-entropy-reducer

## Description

A tool that lowers PE binary entropy to evade heuristic detection by AV and anti-cheat scanners.
Manipulates section padding and data distribution to reduce Shannon entropy scores that would otherwise flag packed or encrypted executables.
