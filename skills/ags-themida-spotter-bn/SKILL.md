# themida spotter bn

**Author:** ergrelet
**Source:** mcp-gamehacking/skills/ags-themida-spotter-bn

## Description

This project focuses on detect Themida/WinLicense and Code Virtualizer's obfuscated code locations.
The plugin has been tested on x86 and x86_64 executables protected with Oreans's products up to version 3.1.9 .
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / binary ninja plugins area.
