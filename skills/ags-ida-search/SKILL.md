# ida search

**Author:** milankovo
**Source:** mcp-gamehacking/skills/ags-ida-search

## Description

This project is an IDA Pro 9.x plugin that brings 010 Editor-style type-aware binary search to IDA.
The ida-plugin.json manifest tells IDA to load plugin.py on startup.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / ida plugins area.
