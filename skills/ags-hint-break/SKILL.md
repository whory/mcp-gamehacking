# hint break

**Author:** sapdragon
**Source:** mcp-gamehacking/skills/ags-hint-break

## Description

This project is a 25-year-old architectural blind spot affecting modern reverse engineering tools.
While most of these have been assigned functions or are correctly parsed, two opcodes — 0F 1A and 0F 1B — remain ghosts in the machine.
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / anti debugging area.
