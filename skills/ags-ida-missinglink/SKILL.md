# ida missinglink

**Author:** kweatherman
**Source:** mcp-gamehacking/skills/ags-ida-missinglink

## Description

This project focuses on fills in missing indirect CALL & JMP target information.
Might not seem that useful at first glance, but can be very helpful for executables that are C++ OOP paradigm heavy to see where the indirect branches go.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / ida plugins area.
