# win32k file collection2

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-win32k-file-collection2

## Description

This project collects many versioned win32k.sys binaries across Windows 10 and 11 builds for offline comparison.
It is a binary corpus for kernel GUI subsystem research rather than a ready-made analyzer.
It is mainly useful for Windows kernel reverse engineers studying win32k changes, syscalls, and input-path internals.
