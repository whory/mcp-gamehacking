# stitch

**Author:** badhive
**Source:** mcp-gamehacking/skills/ags-stitch

## Description

This project is a C++ binary rewriting and obfuscation framework for x86 code. It provides function relocation, global reference patching, complex obfuscation transformations, and branch handling through CMake-built examples demonstrating various code manipulation techniques. It is mainly useful for binary protection researchers and reverse engineers studying x86 code obfuscation and binary rewriting methodologies.
