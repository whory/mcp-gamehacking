# DLL Hijack ExportDumper

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-dll-hijack-export-dumper

## Description

A tool that dumps DLL export tables to generate proxy DLL source code for DLL hijacking attacks.
Automates the creation of export forwarding stubs, enabling side-loading of malicious code through legitimate DLL search order exploitation.
