## Description

This project focuses on itanium + MSVC symbol demangler; D/Rust/Swift; cross-platform replacement for c++filt / undname.exe.
It can also demangle D, Rust, and Swift symbols.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / re tools area.
