# VulnerableKernel Driver

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-vulnerable-kernel-driver

## Description

This project is a deliberately vulnerable Windows kernel driver created for educational purposes. It exposes intentionally insecure IOCTL handlers demonstrating common driver vulnerabilities including arbitrary memory read/write, buffer overflow, use-after-free, and race conditions. The driver serves as a learning target for kernel exploitation practice. It is aimed at kernel exploitation students and security trainers teaching driver vulnerability classes.
