# binaryninja pcode

**Author:** pd0wm
**Source:** mcp-gamehacking/skills/ags-binaryninja-pcode

## Description

This project is a Binary Ninja plugin that bridges Ghidra's Sleigh disassembler and p-code intermediate representation into Binary Ninja's architecture framework. The C++ plugin integrates Ghidra's third-party decompiler components and includes experimental Low Level IL translation from p-code. It is mainly useful for reverse engineers who want to leverage Ghidra's processor definitions and p-code analysis within the Binary Ninja environment.
