# IDAPro MuiLs

**Author:** PoP-Lin
**Source:** mcp-gamehacking/skills/ags-ida-pro-mui-ls

## Description

IDAPro-MuiLs is an IDAPython plugin that applies a restrained modern dark theme to IDA Pro 9.3 while preserving native workspace behavior. Implemented in Python with PySide6 and scoped Qt stylesheets, it restyles menus, toolbars, docks, dialogs, choosers, graph views, scrollbars, and compatible third-party plugin panels. Key features include automatic startup with persistent settings, continuous rounded row selection in Functions, Names, and Strings views, customizable fonts, accent colors, density, and corner radius with live preview, and smooth Windows resize handling with dark title bar integration. The plugin targets Windows 11 reverse engineering workflows where analysts want a cleaner, more readable IDA interface without altering core disassembly or navigation behavior.
