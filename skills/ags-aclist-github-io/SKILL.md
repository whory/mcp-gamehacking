# aclist.github.io

**Author:** aclist
**Source:** mcp-gamehacking/skills/ags-aclist-github-io

## Description

This project is a static website that publishes anti-cheat compatibility information and related Linux gaming documentation.
It is built with HTML, CSS, and JavaScript and includes a curated compatibility list plus guides for companion tools.
The content is based on conservative manual verification of how anti-cheat protected games behave on Linux systems.
It primarily serves Linux gamers and game security researchers tracking platform support and anti-cheat interoperability.
