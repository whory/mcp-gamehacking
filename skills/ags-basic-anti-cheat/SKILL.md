# Basic Anti Cheat

**Author:** gmh5225
**Source:** mcp-gamehacking/skills/ags-basic-anti-cheat

## Description

This project is a basic anti-cheat implementation demonstrating fundamental game protection techniques. It includes process integrity checking, known cheat signature scanning, debugger detection, suspicious module enumeration, and memory region validation. The simple C/C++ implementation serves as a learning resource for understanding core anti-cheat concepts. It is aimed at game security beginners learning anti-cheat fundamentals.
