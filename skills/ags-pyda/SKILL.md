# pyda

**Author:** ndrewh
**Source:** mcp-gamehacking/skills/ags-pyda

## Description

This project is Pyda, a Python-based dynamic binary analysis framework built on QEMU's user-mode emulation. It allows running and instrumenting Linux binaries with Python callbacks for function hooking, memory access monitoring, system call tracing, and instruction-level analysis without requiring native execution. The framework provides a scriptable interface for binary exploration and vulnerability research. It is aimed at security researchers and reverse engineers who prefer Python-based binary analysis workflows.
