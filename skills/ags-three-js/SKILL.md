# three.js

**Author:** mrdoob
**Source:** mcp-gamehacking/skills/ags-three-js

## Description

Comprehensive JavaScript 3D library providing WebGL and WebGPU renderers, a scene graph with cameras/lights/meshes, material/shader systems (PBR, TSL node-based shaders), loaders for glTF/FBX/OBJ, animation mixers, post-processing passes, physics integration, and XR support. The de facto standard for browser-based 3D rendering used extensively in web game development.
