# DrawIDA

**Author:** idkhidden
**Source:** mcp-gamehacking/skills/ags-draw-ida

## Description

This project focuses on lightweight whiteboard plugin for IDA that allows reverse engineers to sketch and brainstorm directly inside IDA.
DrawIDA is licensed under the MIT License – see the LICENSE file for details.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / ida plugins area.
