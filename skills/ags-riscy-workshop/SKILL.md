# RiscyWorkshop

**Author:** mrexodia
**Source:** mcp-gamehacking/skills/ags-riscy-workshop

## Description

Workshop materials for RISC-V based payload obfuscation, featuring a custom VM interpreter (riscvm), a C-to-RISC-V cross-compiler toolchain (llvm-mingw), and an obfuscator that applies liveness analysis and instruction mutation to RISC-V binaries. Includes exercises covering VM basics, shellcode generation, host API interaction, transpilation, and anti-analysis hardening techniques.
