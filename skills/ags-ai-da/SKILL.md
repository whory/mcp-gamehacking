# AiDA

**Author:** sigwl
**Source:** mcp-gamehacking/skills/ags-ai-da

## Description

This project is an AI-powered assistant for IDA 9.0+ to accelerate reverse engineering of C++ games.
These are crucial for many C++ applications on Windows.
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / ida plugins area.
