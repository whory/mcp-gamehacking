**Author:** waldo-vision

## Description

This project focuses on deep Learning.
While running, the program will display a window that shows the gameplay that is currently being analyzed along with the number of clips recorded so far.
It is mainly useful for anti-cheat engineers and defensive security researchers working in the anti cheat / detection:triggerbot & aimbot area.
