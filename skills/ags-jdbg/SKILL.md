# JDBG

**Author:** roger1337
**Source:** mcp-gamehacking/skills/ags-jdbg

## Description

This project is JDBG, a lightweight Java debugger that allows attaching to and inspecting running Java/JVM processes. It provides method hooking, breakpoint setting, variable inspection, and class enumeration through the JVM Debug Interface (JDWP). The tool can be used for runtime analysis of Java-based game clients and obfuscated Java applications. It is aimed at Java reverse engineers and security researchers analyzing JVM-based applications.
