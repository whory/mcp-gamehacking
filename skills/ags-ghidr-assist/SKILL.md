# GhidrAssist

**Author:** jtang613
**Source:** mcp-gamehacking/skills/ags-ghidr-assist

## Description

This project is an LLM extension for Ghidra to enable AI assistance in RE.
It supports any OpenAI v1-compatible API, including local models (Ollama, LM-Studio, Open-WebUI) and cloud providers (OpenAI, Anthropic, Azure).
It is mainly useful for game security researchers and reverse engineers studying offensive techniques working in the cheat / ghidra plugins area.
